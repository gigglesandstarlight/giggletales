<h2>About the Project</h2>

<p>
  GiggleTales is a personal software development
  project created to make reading more engaging
  and interactive for young children.
</p>

<p>
  Built with React Native and Expo, the application
  features a collection of illustrated children's
  stories with interactive navigation and optional
  audio narration.
</p>

<h2>Features</h2>

<ul>
  <li>Interactive digital storybooks</li>
  <li>Read-to-me audio narration</li>
  <li>Illustrated storytelling experiences</li>
  <li>Child-friendly navigation and interface</li>
  <li>Multiple original and adapted stories</li>
</ul>

<h2>Project Development</h2>

<p>
  GiggleTales was independently designed and

  development, testing, and iOS distribution
  preparation.
</p>

<p>
  The project provided hands-on experience in:
</p>

<ul>
  <li>Mobile application architecture</li>
  <li>React component development and state management</li>
  <li>User interface design and navigation</li>
  <li>Audio integration and interactive features</li>
  <li>Debugging and iterative development</li>
  <li>Application testing and deployment</li>
</ul>
